# 六种界面交互模式

以下内容整理自用户提供的视频中可观察到的交互。视频展示效果不是适用于所有产品的规范；实现时依据项目、平台约定和用户任务取舍。无需读取无关模式。

## 1. 堆叠头像或卡片

**适用**：参与者预览、收藏、相似项目等，需要在较小空间表达“多个对象”。

**实现**：以容器管理重叠间距和层级；保持稳定顺序。限制可见数量，超出显示“+N”，点击数量进入完整列表。空间不足时降低数量而不是无限缩小。若卡片可操作，保证重叠部分不会遮住其主要按钮。

**可访问性**：屏幕阅读器得到完整且不重复的人名/数量。整组只需要一个查看入口时，不让装饰头像分别占用键盘焦点；每个头像有独立操作时使用真正的按钮或链接并提供可辨识名称。

**检查**：0/1/多个对象、加载失败头像、长姓名、窄屏、键盘焦点可见、点击区域不被上一层遮挡。

## 2. 选项与标题联动

**适用**：分类、套餐、任务状态等选择会改变页面语义或下一步操作，需要立即解释选择结果。

**实现**：使用同一个选中状态驱动标题、说明、内容和操作按钮，避免各自维护造成不一致。异步内容切换要防止旧请求覆盖新选项。标题容器允许长文本换行；动画期间避免页面突然跳动，不为了固定高度裁切重要文案。

**可访问性**：用与选择模型相符的单选组、标签页或按钮组。提供选中状态与键盘操作。只在变化不明显且有必要时用温和的状态播报，避免标题和内容重复朗读。

**检查**：快速连续切换、默认选择、后退或刷新后的状态（如产品要求保留）、长文案、异步失败与加载状态、减少动态效果。

## 3. 与页面连贯的底部面板

**适用**：仍需参考背景内容的轻量编辑或上下文补充。视觉上可使用同色表面、柔和边界和连贯圆角，减少割裂感。

**实现**：先决定是否允许操作背景。背景继续可操作时做非模态面板，通常无需遮罩；不得设置 aria-modal 或锁住焦点。必须完成/取消才能继续的流程仍使用模态对话框、焦点约束及适当遮罩；“无蒙层”不是强制要求。提供明显的关闭或完成入口，处理底部安全区、滚动和屏幕键盘遮挡。

**可访问性**：模态打开后焦点进入面板、Escape 关闭且焦点返回触发器。非模态允许正常访问背景，保持有意义的顺序。拖动手柄仅是补充，不作为唯一关闭方式。

**检查**：桌面和手机、面板内长内容、输入法弹出、背景滚动、关闭后状态保留、键盘操作、减少动态效果。

## 4. 日历空白日期快捷新建

**适用**：日记、记录、习惯、预约等，用户常从某个没有内容的日期开始创建。

**实现**：可用的空白日期也是明确的操作入口，点击后携带准确日期进入编辑。区分“有效日期没有记录”和“月首/月尾的占位格”；占位格不可凭空创建记录。禁用日期、未来日期、历史日期和时区遵循业务规则。已有记录打开详情，多个记录则先展示列表或项目规定的入口。

**可访问性**：可操作日期使用按钮/链接，名称包含完整日期和是否有记录。已有日历组件时遵守其网格键盘规则；不要仅靠颜色区分状态，也不要把无语义 div 变成唯一点击入口。

**检查**：跨月跨年、闰年、用户时区、月边界占位、禁用日期、点击后预填日期、创建取消后返回位置、重复提交。

## 5. 底栏主操作直达编辑

**适用**：新增是高频任务，底栏有清晰主操作，且默认创建类型可确定。

**实现**：点主按钮直接进入已准备好的编辑状态；只有存在必须先选择的类型或权限时才保留中间步骤。保留返回来源、日期等上下文，避免重复点击创建多个编辑器。草稿脏状态按项目规则提示、暂存或恢复；不要每次取消都静默丢弃。

**可访问性**：主按钮有“新增记录”等明确名称，不只朗读“加号”。遵守平台点击区域和安全区规范，焦点进入编辑器后可顺畅返回。

**检查**：重复点击、无权限、离线、草稿恢复、取消和保存后返回、页面刷新、屏幕键盘与底栏布局。

## 6. 图片与标题同步滑动

**适用**：内容故事、主题卡片、产品浏览等，图片与标题共同描述一个项目。

**实现**：图片、标题、说明和操作共用一个索引或同一个滑动容器；滑动期间和结束后不能错配。明确首尾行为及当前位置，保留垂直滚动的手势判断，避免左右滑动吞掉页面上下滚动。默认不自动轮播，除非任务明确需要；自动播放必须能暂停。

**可访问性**：提供按钮或等效键盘入口，滑动不是唯一途径。非当前页的操作不进入焦点顺序。图片替代文字描述必要信息，不重复紧邻标题。减少动态效果时采用直接切换或很短的渐变。

**检查**：1/多个项目、图片未加载、快速滑动、首尾边界、点击链接与拖动区分、横竖屏、长标题、键盘与触屏、减少动态效果。
