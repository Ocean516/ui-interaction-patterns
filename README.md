# 界面交互技巧

把六种界面交互整理为可复用的 Codex 技能，依据实际需求选择，不要求用户记住技能名。

包含：堆叠头像/卡片、选项联动标题、连贯底部面板、日历空白日期快捷新建、底栏主操作直达编辑、图片和标题同步滑动。每种模式包含适用条件、实现边界、可访问性和验证要点。

## 在 Codex 中使用

本机已安装到 `CODEX_HOME/skills/ui-interaction-patterns`。重新打开 Codex 后直接描述任务，例如：

- “帮我让这个日历的空白日期可以直接写记录。”
- “分类切换时，上面的标题和内容一起变化。”
- “底栏的加号直接进入编辑，顺便处理草稿恢复。”

现有的自动技能选择规则会结合描述选取技能；`agents/openai.yaml` 同时允许隐式调用。自动选择依赖任务匹配，无法保证每句模糊请求都触发，也不会为所有界面强行加入六种效果。

也可以明确指定 `$ui-interaction-patterns`。

## 换电脑安装

把 `skills/ui-interaction-patterns` 整个目录复制到自己的 `CODEX_HOME/skills/`（通常为用户目录下 `.codex/skills/`），重新打开 Codex。仓库同时附带 `.codex-plugin/plugin.json` 作为插件格式包装；本次本机采用直接安装技能，无需额外接入第三方服务。

技能可与已安装的 UI 设计、浏览器检查和发布能力协作；普通问答、后台任务及逆向分析不会因为此技能而改变流程。

本仓库只保存整理后的技能文件，不包含用户视频、个人设置、账号信息或 REA 安装文件。REA 单独保存在 https://github.com/Ocean516/rea 。
